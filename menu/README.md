# menu

Starts a tool (lazygit, gh-dash, VS Code…) from a `Tools` pane of icons above the file explorer of herdr-explorer, or from a popup menu opened by one key; also updates Herdr and the plugins installed from GitHub, its icon green when one has a new version, and sets the plugins from a settings screen. Requires Herdr 0.9.5 or later. Displayed text is in French for now.

```sh
herdr plugin install IMSike/Herdr-Plugins/menu
```
