# menu

Starts a tool (lazygit, gh-dash, VS Code…) from a `Tools` pane of icons above the file explorer of herdr-explorer, or from a popup menu opened by one key (lazygit, gh-dash, VS Code and btop also each from a key of their own); also sets the plugins from a settings screen, which updates Herdr and the plugins installed from GitHub (its icon green when one has a new version) and recovers the panes and agents a session lost from Herdr's snapshots. Requires Herdr 0.9.5 or later. Displayed text is in French for now.

```sh
herdr plugin install IMSike/Herdr-Plugins/menu
```
