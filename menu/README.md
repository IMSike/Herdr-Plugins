# menu

Starts a tool (lazygit, gh-dash, VS Code…) from a `Tools` pane of icons above the file explorer of herdr-explorer, or from a popup menu opened by one key.

```sh
herdr plugin install IMSike/Herdr-Plugins/menu
```
