# links

Opens the paths the Claude Code plugin [dx](https://github.com/IMSike/CC-Plugins) makes clickable in Claude's replies, on a ctrl+click in Herdr: herdr-explorer's preview, the File Explorer, or the program Windows associates with the file, as set in `links.toml`. A folder is selected in the File Explorer; a file whose type is not on the list of open types is never opened with its program unless a Danger setting allows it, after a confirmation by default. Windows only; requires Herdr 0.9.5 or later. Displayed text is in French for now.

```sh
herdr plugin install IMSike/Herdr-Plugins/links
```
