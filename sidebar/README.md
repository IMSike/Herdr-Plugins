# sidebar

A workspace → agents tree in Herdr's Agents panel, with CPU, memory and shell counts; the totals of all panes and of the whole machine in the tab bar. Requires Herdr 0.9.5 or later. Displayed text is in French for now.

```sh
herdr plugin install IMSike/Herdr-Plugins/sidebar
```
